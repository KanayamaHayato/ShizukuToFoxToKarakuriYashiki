# 雫と狐とからくり屋敷
## 先進プロジェクト実験１
チーム「黄金の傘」　による和風ホラー探索型ゲーム制作ポロジェクト

---

## 🎮 ゲーム概要

現代の高校生「桜屋敷 雫」が迷い込んだのは、
怪しく歪んだ”からくり屋敷”。

🏮灯籠🏮に火を灯し、
謎の狐🦊「屋代」に導かれ、
仕掛けだらけの屋敷🏯から脱出を目指す

和風 x ホラー x 探索 x 謎解き をテーマにした
3Dアクションホラーゲーム

---

## 特徴

- 自動生成される和風迷路🏯
- 不気味な雰囲気重視のホラー演出👁
- からくり屋敷特有のギミック・謎解き⚙
